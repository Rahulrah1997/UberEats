# Uber Eats Analytics Dashboard

A Streamlit dashboard for analyzing Uber Eats restaurant and order data.

## Features

- Restaurant Analysis
- Order Analysis
- Interactive Charts
- SQLite Database
- Data Cleaning using Pandas

## Technologies Used

- Python
- Streamlit
- Pandas
- SQLite

## Installation

```bash
git clone https://github.com/Rahulrah1997/UberEats.git
cd UberEats
pip install -r requirements.txt
```

## Run the project

```bash
streamlit run app.py
```
